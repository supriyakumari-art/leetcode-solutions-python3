LeetCode 389 - Find the Difference
Problem Description

You are given two strings s and t.

String t is generated by shuffling string s and adding one extra character.
Find and return the character that was added to t.

Example

Input:

s = "abcd"
t = "abcde"


Output:

"e"


Explanation: The character e was added to string t.

Approach
Iterate through each character in string t.
Count how many times the character appears in s and t.
If the counts differ, that character is the extra character.
Return the extra character.
Complexity Analysis
Time Complexity: O(n²), because count() scans the string for each character.
Space Complexity: O(1), as no additional data structures are used.
